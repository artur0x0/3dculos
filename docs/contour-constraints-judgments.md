# Contour constraints — judgment calls

Artur said GO on the contour plan, with the amendments below. Every question he did not mention keeps the plan default. Each row is locked. The pull request column is where the behavior lands.

The word in the UI and in docs is contour. Code identifiers in new files are `contour*` as well, because the files are new and renaming later would be the noisy path. Joints keep their own solver.

| 23 | A contour may contain more than one chain, so two separate edges can take an angle or a distance. | 24 | Arc and Dimension are gestures, not members of `CONTOUR_TOOLS`. Selecting one does not call `switchContourTool` and does not clear the contour. | 25 | Promotion runs when Arc or Dimension is selected, so the pick has ids. Cancel writes nothing. The promotion stays in the session until a different profile tool replaces it. | PR B |

Contour picks live on the mode state. `useStickyPick` is the same rule for a card that owns its list. The joints card uses the same `StickyPickApply` and keeps the rich fingerprints on the parent list. A placed joint uses the same Delete and X tag popup. | PR B component. Joints card follows. |
| 27 | Dimension Confirm does not Auto-Run and does not leave contour mode. It replaces the profile expression inside an existing Extrude, Revolve, Loft, or Sweep block and leaves the solid lines alone. Loft replaces the selected station. With no block yet, it inserts the profile block. An open contour stays in the session and is not emitted until it has a closed loop. | PR B |
| 28 | A dimension name is checked only inside the contour. It is not checked against script bindings, because it is not a `const`. | PR B |
| 29 | Arc on a circle says a circle has no corner. Arc on a rectangle, polygon, or polyline promotes if needed, then rounds two or three adjacent lines. The radius is the arc seed. Tangent constraints are added. A conflict still returns the closest shape. | PR B |
| 30 | After placement, a dimension is a floating tag. Tapping it opens Delete and X. It does not reopen the dimension card. Labels show only while that contour is open. | PR B |
| 31 | Constraints is a gesture, id `constraints`, rail title Constrain, Lucide `Link2`. It is not a profile tool. Confirm uses the same profile write as Dimension and stays in the gesture. | PR C |
| 32 | A placed constraint is a floating icon (`data-contour-icon`). Tapping it opens Delete and X. It does not reopen the card. | PR C |
| 33 | Suggestion boundaries are inclusive. A line at 20° from +u is in the horizontal band; at 70° from +u is in the vertical band. Between them, the longer axis suggests the kind, and a tie suggests horizontal. Two lines at 15° from parallel suggest parallel; at 75° from parallel suggest perpendicular; between them suggest parallel. Two arcs are nearly tangent when the center distance is within 10% of the sum of the radii or of the difference. Radii within 10% suggest equal when the pair is not nearly tangent. Equal of a line and an arc is not offered. Tangent side is the sign of the current separation. | PR C |
